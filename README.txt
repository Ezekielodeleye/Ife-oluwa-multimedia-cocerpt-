IFE OLUWA MULTIMEDIA CONCEPT WEBSITE

HOW TO USE
1. Extract the ZIP file.
2. Open index.html in a browser to preview the website.
3. Upload the files to a GitHub repository to publish with GitHub Pages:
   - Repository Settings -> Pages
   - Choose Deploy from a branch
   - Select main and /(root), then Save.

CUSTOMIZE
- Replace the sample gallery photos in index.html with your own photography.
- Edit the text and phone/social links in index.html if any details change.
- The gallery filters and image lightbox work using script.js.
- The website is responsive for phones, tablets and computers.
